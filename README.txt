VOLUME ONE WEBSITE STARTER

Files:
- index.html
- style.css
- script.js

Before launch:
1. Replace the WhatsApp number in index.html: wa.me/91XXXXXXXXXX
2. Replace the phone number and email address in the contact section.
3. Replace the three project photo placeholders with your own project images.
4. Review the wording and service area.

Deploy using GitHub Pages:
1. Create a PUBLIC repository on GitHub named volumeone-website (or another name).
2. Upload all three files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Once the GitHub Pages URL is live, open Settings > Pages and add VolumeOne.in under Custom domain. Save.
6. Only after adding the custom domain in GitHub, update the GoDaddy DNS records using the current GitHub Pages documentation.
7. Preserve all MX, TXT, and email-related records. Do not change nameservers.

Official documentation:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
https://www.godaddy.com/en-in/help/manage-dns-records-680
